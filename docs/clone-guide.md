# Clone Detection Guide

## What is a Clone?

Many retro handhelds sold on AliExpress, Amazon, and other marketplaces are clones — devices that look identical to a known brand but use different (usually cheaper) hardware inside.

## Common Clone Indicators

1. **Allwinner A33 SoC** — The A33 is a very old, cheap ARM chip. Genuine R36S devices use Rockchip RK3326. If your card has A33 signatures, it's almost certainly a clone.

2. **No custom firmware support** — Clone hardware typically cannot run custom firmware (CFW) designed for the genuine device.

3. **Different bootloader** — Genuine Rockchip devices use idbloader; clones often use Allwinner eGON.

## What To Do If You Have a Clone

- The device still works for its intended purpose (playing retro games)
- Stock firmware is typically the only option
- Consider it a learning experience about marketplace purchases
